# NHANES-Risk-Factor-Analysis

Cardiovasula Disease &amp; Asthma prediction analysis based on NHANES dataset (2000-2018). 
Analysed for specific health markers and lifestyle habits of the adult population. Demographic information was also used for analysis for disease diagnosis (ie. age, sex)

Link to Tableau dashboard of visualisations: https://public.tableau.com/app/profile/hai.nguyen5235/viz/vis_data/Viz1
 
*This project was created for the TDP unit assignment and was completed as part of a team.*
